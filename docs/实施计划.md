# Codex Atlas 实施计划

> 面向 agent 执行：每个阶段都必须按“背景信息 -> 小方案 -> 开发 -> 测试/验证 -> 独立审查 -> 修复”的顺序推进。所有文件创建、缓存和构建产物都必须留在当前项目目录。

## 总目标

交付一个 Windows 个人自用的轻量 Codex 能力字典侧边栏：源码、可执行文件/便携包、中文说明、测试和审查记录齐全。

## 目录规划

- `cmd/codex-atlas/main.go`：程序入口，初始化配置、扫描器、存储和主窗口。
- `internal/domain/`：能力、统计、用户数据、AI 数据等核心类型。
- `internal/config/`：Codex 路径、应用数据路径、构建内缓存路径说明。
- `internal/scanner/`：skills、plugins、tools、apps 扫描。
- `internal/store/`：项目内 JSON 持久化、合并规则。
- `internal/stats/`：历史会话统计。
- `internal/ai/`：本机 `codex` CLI 离线整理封装。
- `internal/ui/`：Windows 侧边栏界面、事件绑定、快捷键。
- `tests/fixtures/`：测试用 SKILL、plugin、session 样例。
- `data/`：运行时本地数据。测试不依赖真实用户数据。
- `dist/`：最终便携包。
- `docs/开发记录.md`：阶段验证、审查和修复记录。
- `docs/使用说明.md`：最终中文使用说明。

## 通用命令约束

所有 Go 命令都用项目内缓存：

```powershell
$env:GOMODCACHE = "$PWD\.cache\gomod"
$env:GOCACHE = "$PWD\.cache\gobuild"
$env:GOPATH = "$PWD\.cache\gopath"
```

常用验证命令：

```powershell
go test ./...
go build -ldflags="-H=windowsgui" -o dist\codex-atlas.exe .\cmd\codex-atlas
```

## 阶段 1：MVP Skills 字典

### 1.1 初始化 Go 项目

- 创建 `go.mod`。
- 引入 `github.com/lxn/walk` 和必要的 Windows API 包。
- 创建基础目录。
- 验证：`go test ./...` 至少能编译空包。
- 审查重点：没有把 Go 缓存写到项目外。

### 1.2 核心数据模型

- 创建 `internal/domain/types.go`。
- 定义 `AbilityKind`、`Ability`、`UserData`、`AIData`、`Stats`、`Store`。
- 写单元测试覆盖用户数据优先级：AI 刷新不能覆盖用户标签、备注、收藏、隐藏、自定义模板。

### 1.3 Skill 扫描器

- 创建 `internal/scanner/skill_scanner.go`。
- 从 `skills/**/SKILL.md` 和插件 `skills/**/SKILL.md` 扫描能力。
- 解析 YAML front matter 和 Markdown fallback。
- 测试 fixture 覆盖：有 front matter、没有 front matter、插件 skill、重名 skill。

### 1.4 JSON 存储和合并

- 创建 `internal/store/json_store.go`。
- 默认写入 `data/atlas-store.json` 和 `data/last-scan.json`。
- 测试覆盖：空文件、损坏 JSON、安全创建目录、用户字段保留。

### 1.5 MVP UI

- 创建 `internal/ui/window.go`。
- 左侧列表 + 搜索 + 过滤，右侧详情 + 动作按钮。
- 实现收藏、隐藏、备注、标签编辑、模板复制、打开文件、打开目录、复制路径。
- 手动验证：启动程序、扫描真实 Codex skills、搜索、打开详情、保存备注。

## 阶段 2：Plugins / Tools / Apps 辅助视图

### 2.1 Plugin 扫描

- 解析 `.codex-plugin/plugin.json`。
- 聚合插件下 skills 数量。
- 测试 fixture 覆盖缺字段、相对 skills 路径、插件说明。

### 2.2 Tools / Apps 视图

- 从 plugin manifest 的 interface、capabilities、MCP/apps 相关字段提取可展示条目。
- 对无法稳定识别的条目标注“本地清单可见/运行时详情未发现”。
- UI 加入 `Plugins`、`Tools`、`Apps` 切换。

## 阶段 3：使用统计

### 3.1 会话扫描

- 创建 `internal/stats/session_stats.go`。
- 流式读取 `sessions/**/*.jsonl`，统计 `$skill-name` 和 skill name。
- 测试 fixture 覆盖多次出现、同会话去重、最近时间。

### 3.2 UI 统计展示

- 列表显示真实使用次数。
- 详情显示真实使用次数和最近使用时间。
- Plugin 统计按下属 skills 聚合。

## 阶段 4：AI 离线整理与刷新

### 4.1 `codex` CLI 封装

- 创建 `internal/ai/codex_cli.go`。
- 输入输出写入项目内 `.tmp`。
- 支持超时、错误输出、JSON 格式校验。
- 测试用假命令覆盖成功、失败、超时、坏 JSON。

### 4.2 AI 字段合并

- 只更新 `AIData`。
- 用户标签、备注、收藏、隐藏和自定义模板保持不变。
- UI 提供“AI 整理当前列表”和错误提示。

### 4.3 手动刷新

- 实现“刷新能力清单”、“刷新使用统计”、“AI 整理当前列表”、“全部刷新”。
- 不加入默认后台定时刷新。

## 阶段 5：侧边栏体验和打包

### 5.1 窗口行为

- 窗口浅色主题。
- 默认靠右侧显示，置顶。
- 全局快捷键显示/隐藏。
- 手动验证：快捷键、置顶、显示隐藏。

### 5.2 打包与说明

- 构建 `dist/codex-atlas.exe`。
- 生成 `docs/使用说明.md` 和根目录 `README.md`。
- 记录启动、扫描和主要交互验证结果。

### 5.3 完成审查

- 运行 `go test ./...`。
- 运行构建命令。
- 运行独立代码审查，检查：性能、写入边界、用户数据优先、错误处理、中文注释、UI 约束。
- 修复审查问题。
- 做最终完成审计。

## 阶段 6：第二版 Skill 详情与翻译缓存

### 6.1 主窗口放大

- 调整默认主窗口宽度，保留短侧边栏形态，但给 Skills 列表、底部详情和详情入口更多横向空间。
- 验证：启动 GUI smoke，确认主列表文字、底部详情和操作按钮没有明显挤压。

### 6.2 Skill 详情窗口

- 在应用层新增 Skill detail 查询，按 Skill ID 读取对应文件夹内的可阅读文件。
- 在 UI 层新增详情窗口：左侧文件列表，右侧内容阅读区。
- 支持 `SKILL.md` 和相邻 Markdown / 文本文件浏览。
- 验证：打开多个 Skill，切换左侧文件，确认路径解析不会逃逸 Skill 目录。

### 6.3 原文 / 译文切换

- 为详情窗口增加原文和译文状态。
- 中文文件默认显示原文，不展示翻译按钮。
- 非中文文件在未命中缓存时显示翻译按钮；缓存命中时默认显示中文译文，并允许切回原文。
- 验证：覆盖中文文件、英文文件、缓存命中、缓存未命中和内容变更。

### 6.4 翻译缓存

- 新增 `data/translation-cache.json`。
- 缓存 key 使用 `skillID + relativePath + contentHash`，避免不同 Skill 或旧内容串用译文。
- 翻译通过本机 `codex exec --ephemeral` 手动触发，只处理当前文件，不做自动批量翻译。
- 构建脚本同步 `data/translation-cache.json` 到 `dist/data/`，不存在时跳过；portable zip 继续包含 `dist/data`。

### 6.5 测试与审查流程

- TDD 优先覆盖 `internal/skilldoc`、`internal/translate`、`internal/ai.Translator` 和 `internal/app` detail 聚合。
- UI 层做轻量单元测试和手动 smoke，重点检查按钮显示规则、缓存命中默认中文和原文切换。
- 子 agent 复审重点：路径边界、缓存 key、不会自动批量翻译、不会覆盖用户整理数据。
- 最终验证命令：
  - `go test ./...`
  - `powershell -NoProfile -Command "$null = [scriptblock]::Create((Get-Content -Raw scripts/build.ps1)); 'ok'"`
  - `powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1`
  - `.\.tmp\codex-atlas-console.exe --smoke-scan`
  - GUI smoke：确认主窗口和 Skill 详情窗口可打开，列表、文件列表、原文 / 译文按钮无明显遮挡。
