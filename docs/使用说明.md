# Codex Atlas 使用说明

## 启动

在项目目录运行：

```powershell
dist\codex-atlas.exe
```

便携运行时请同时保留：

- `codex-atlas.exe`
- `codex-atlas.exe.manifest`

manifest 是 Windows 原生控件所需文件，缺少它可能导致程序启动失败。

## 主界面

- 顶部按钮切换 `Skills`、`Plugins`、`Tools`、`Apps`。
- 搜索框可以按名称、标签、摘要、场景、备注过滤。
- 快速筛选按钮支持 `常用`、`调试`、`写文档`、`设计`、`隐藏`；再次点击同一按钮会取消筛选。
- 主列表显示能力名称、标签和使用次数；没有新版统计缓存时显示 `未统计`，避免误显示为 0。
- 鼠标悬停在列表项上时，底部状态栏显示一句话说明。
- 底部详情抽屉展示摘要、来源路径、类型和调用模板。
- 默认窗口是短侧边栏，用户可以手动拖高；拖高后列表区域优先增加空间。

## 更多面板

点击 `更多` 会展开低频动作：

- `打开文件`：打开来源文件，例如 `SKILL.md`。
- `打开目录`：打开来源所在目录。
- `复制路径`：复制来源路径。
- `完整详情`：查看真实名称、来源、状态、原始描述、适用/不适用场景、相似能力、完整调用模板、统计和完整路径。
- `刷新清单`：重新扫描 Codex 能力文件和插件清单。
- `刷新统计`：重新统计 Codex 历史会话，并写入当前项目统计缓存。
- `AI 整理`：调用本机 `codex exec --ephemeral` 整理当前可见列表。
- `全部刷新`：刷新清单后刷新统计。
- 排序下拉框支持默认、名称、使用次数、最近使用。

刷新、统计和 AI 整理运行期间，界面会临时禁用相关按钮，避免重复触发任务或和保存个人整理并发写入。

## Skill 详情窗口

在 Skills 视图选中一项后，可以点击底部 `打开详情`，也可以双击列表项打开第二版详情窗口。`更多 -> 完整详情` 保留为第一版文本详情。

- 左侧文件列表显示该 Skill 文件夹下可阅读的 Markdown、文本、常见代码和配置文件，通常包括 `SKILL.md` 以及相邻说明文件；会自动跳过 `.git`、`node_modules`、`dist` 等目录以及过大或不可预览文件。
- 点击左侧文件名后，右侧会显示对应文件内容。
- 右侧支持 `原文` 和 `译文` 两种视图，可以随时切换。
- 如果文件本身是中文，详情窗口默认显示原文，不显示翻译按钮。
- 如果文件不是中文，并且没有命中缓存，会显示翻译按钮；点击后才会调用本机 `codex exec --ephemeral` 生成中文译文。
- 如果翻译缓存命中，默认显示中文译文，同时保留切回原文的入口。
- 翻译按钮只对当前打开的文件生效，不会自动批量翻译整个 Skill 文件夹。

## 个人整理

选中一个能力后，点击 `编辑` 可以整理：

- 中文名或个人别名。
- 手动标签。
- 自定义调用模板。
- 备注。
- 收藏。
- 隐藏。

点击“保存整理”后，个人数据写入当前项目的 `data/atlas-store.json`。AI 整理和重新扫描不会覆盖这些手动字段。

## 常用动作

- `复制模板`：复制第一个调用模板；如果填写了自定义模板，会优先复制自定义模板。
- `更多`：展开文件、路径、刷新、排序和 AI 整理。
- `编辑`：展开别名、标签、模板、备注、收藏和隐藏。

## 快捷键

全局快捷键：

```text
Ctrl + Alt + Space
```

用于显示或隐藏 Codex Atlas 侧边栏。

## 数据和边界

- Codex Atlas 只读 `%USERPROFILE%\.codex` 或 `CODEX_HOME` 指定目录。
- 当前项目外的 Codex skills、plugins、sessions 不会被修改。
- 应用自己的数据写在当前项目 `data/`。
- 使用统计缓存写在当前项目 `data/stats-cache.json`，下次启动直接读取，避免每次打开都全量扫描历史会话；旧版统计缓存会被视为未知统计，需要点击 `刷新统计` 重新生成。
- 翻译缓存写在当前项目 `data/translation-cache.json`。缓存 key 绑定 Skill、相对文件路径和内容哈希，文件内容变化后会重新视为未翻译。
- AI 临时输入输出写在当前项目 `.tmp/`。
- Go 构建缓存写在当前项目 `.cache/`。

## 重新构建

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

构建结果：

- `dist/codex-atlas.exe`
- `dist/codex-atlas.exe.manifest`
- `dist/codex-atlas-portable.zip`
- `dist/使用说明.md`
- `dist/data/last-scan.json`
- `dist/data/stats-cache.json`
- `dist/data/translation-cache.json`：仅当当前项目存在翻译缓存时生成，并会包含在 `codex-atlas-portable.zip` 中。

## 验证记录

本机验证结果：

- `go test ./...`：通过。
- 真实扫描 smoke：`codexHome=C:\Users\Administrator\.codex abilities=120 skills=87`。
- 新版统计缓存：`87` 项，非零使用次数 `39` 项。
- GUI 启动 smoke：进程响应正常，主窗口和独立 Skill 详情窗口可以打开，工作集约约 `27.4MB`，CPU 时间约 `0.25s`，列表截图显示 `N 使用`。

## 已知限制

- AI 整理依赖本机 `codex` 命令可用，并且可能需要较长时间；失败时不会影响本地扫描和个人整理。
- Tools/Apps 来源于插件本地清单，不做实时会话工具发现。
- 使用统计来自项目缓存；需要最新数据时点击 `更多 -> 刷新统计`。
- 当前版本是 Windows 个人自用工具，不包含云同步、账号、团队共享和内置聊天。
