# 使用说明

本文面向 Codex Atlas Rust/Tauri 版的日常使用者。当前项目是 Rust + Tauri v2 重写版，不是旧 Go + Walk 程序；所有用户整理数据都保存在当前项目 `data` 目录，外部 Codex roots 只读。

## 主界面

启动应用后，主窗口显示“能力索引”。顶部的“扫描”会重新读取本机 Codex 普通 Skill、插件 Skill，并在常见 Codex catalog manifest 存在时读取 plugins、tools、apps；不存在的 manifest 会直接跳过，不会产生扫描噪音。“统计”会重新读取 Codex 会话 JSONL 并刷新使用次数。扫描只替换原始能力列表，不会清空用户已经保存的收藏、隐藏、备注、标签和自定义模板。

搜索框会同时匹配能力 id、名称、别名、摘要、中文摘要、备注、路径和标签。类型分段按钮支持 `Skills`、`Plugins`、`Tools`、`Apps`、`All`；默认以 Skill 为主。筛选区里的“常用”只显示已收藏能力，“隐藏”切换到隐藏视图；隐藏能力默认不出现在普通列表中。标签下拉会按当前能力标签过滤。

排序支持三种方式：按使用次数、按名称、按类型。按使用次数排序时，有可信统计的能力排在未知统计前面，次数越高越靠前；同分时按中文环境下的名称排序。列表每一行展示能力名称、摘要、最多四个标签、使用统计和语言状态。

选择某个能力后，底部详情区会展示路径、摘要、使用次数和标签。点击“复制模板”会复制调用模板：优先使用用户自定义模板，其次使用 AI 模板，最后回退到默认 `$skill-name` 或 `$ability-id`。点击“更多”可以收藏或取消收藏、隐藏或取消隐藏，并编辑备注、标签和自定义模板。标签输入支持英文逗号、中文逗号和换行分隔；保存后用户标签优先于 AI 标签和原始标签。

## Skill 详情窗口

只有 `Skill` 类型能力支持“打开详情”。在真实 Tauri 运行时，它会打开一个独立详情窗口；在前端测试或浏览器 mock 环境中，会以内嵌弹层模拟详情窗口。

详情窗口左侧是 Skill 文件列表，右侧是只读阅读器。文件列表只枚举 Skill 根目录内的可阅读文本文件，例如 Markdown、JSON、YAML、TOML、Rust、TypeScript、CSS、HTML、Shell、PowerShell 等。依赖目录、构建目录、二进制文件、过大文件、过深目录会被跳过，并在需要时显示 warning。当前实现限制包括最大深度、最大文件数和单文件大小；这些限制用于避免详情窗口误读大型依赖或构建产物。

详情阅读器不能写入 Skill 文件，也不能通过 `..`、绝对路径、symlink 或目录联接越过 Skill 根目录。后端会对 Skill 入口文件和每次读取的相对路径做 canonical 路径校验，确认真实路径仍在同一个 Skill 根目录内。

## 翻译

详情窗口会在读取当前文件后检查语言和缓存。英文或其他非中文内容、且没有缓存命中时，右上角显示“翻译”按钮；中文内容会隐藏翻译按钮。翻译是单文件、手动触发的慢操作，不会自动批量翻译整个 Skill 仓库，也不会遍历目录。

翻译通过本机 `codex exec --ephemeral` 执行，提示词、输入和输出都写到项目 `.tmp`，译文缓存写到 `data/translation-cache.json`。缓存 key 由 `skillId + relativePath + contentHash` 组成，所以同一个文件内容变化后旧译文不会误命中。缓存命中时，阅读器默认显示中文译文，并在语言区域显示“缓存命中”；手动刚翻译出的结果会立即显示，并写入缓存。

如果外部 Codex 命令超时、失败、返回空译文，或者缓存 JSON 损坏，界面会显示中文错误信息。错误不会修改原始 Skill 文件，也不会破坏用户备注、标签或收藏。

## 统计显示

`N 使用` 表示当前能力有可信统计结果，`N` 是 usage_count。统计来源包括用户消息中显式出现的 `$skill`、`$plugin:skill`，以及助手实际读取对应 `SKILL.md` 的记录。同一条消息或同一会话里重复显式点名会重复计数。

`未统计` 表示还没有可信统计来源，或本轮统计 discovery 不完整。它不是 `0 使用`。当会话目录不存在、部分 JSONL 无法读取、存在坏 JSONL 行，或者统计根目录为空时，应用会保留已有统计或未知状态，避免把“没读到”误写成 0。

## 常用验证和打包命令

日常开发可以先运行骨架验证：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/验证项目骨架.ps1
```

类型检查和前端测试：

```powershell
npm run typecheck
npm run test:frontend
```

Rust 测试和 smoke：

```powershell
npm run test:rust
npm run smoke:scan
npm run smoke:skill-detail
npm run smoke:translation-cache
npm run smoke:gui
```

前端构建和 Tauri 打包：

```powershell
npm run build
npm run tauri:build
```

`smoke:gui` 会启动脚本自己的 Vite dev server，并把 Playwright Chromium 缓存放在项目 `.cache`。真实扫描 smoke 只读外部 Codex roots；如果本机没有可扫描数据，会说明跳过而不是失败。
